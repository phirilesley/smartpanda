## 🚀 **BUILD & DEPLOYMENT**

### **📱 Build Student App:**
```bash
# Build Student App (Android)
cd mobile
.\scripts\build-all-platforms.bat

# Generated Files:
dist/android/SmartPanda_Student_Android_Debug.apk
```

### **🍎 Build Student App (iOS):**
```bash
# Build Student App (iOS - requires Mac)
cd mobile
npm run build:ios:student

# Generated Files:
dist/ios/SmartPanda_Student_iOS_Debug.ipa
```
